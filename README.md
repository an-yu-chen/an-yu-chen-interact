# Meaning in Motion — InterACT VUB Fellowship Website

A static GitHub Pages site for the proposed InterACT postdoctoral project:

**How does a high-tech opportunity change meaning as it moves between communities of evaluation?**

## Files
- `index.html` — main website
- `style.css` — responsive visual design
- `script.js` — smooth navigation

## Important evidence convention
The website distinguishes:
- **Observed / documented case evidence:** VUB TechTransfer and VUB Research Portal facts.
- **Planned pilot targets:** proposed sample sizes and measures. These are not research results.

Before public release, replace the placeholder/shortened VUB case URL in the Optrima/SoftKinetic card with the full official VUB URL and add your own ORCID/profile links.

## Publish with GitHub Pages
1. Create a GitHub account if needed.
2. Create a repository named `<yourusername>.github.io`.
3. Upload these three files plus this README.
4. Go to Settings → Pages.
5. Under Build and deployment, choose “Deploy from a branch”.
6. Select `main` and `/ (root)`, then Save.
7. Your site will appear at `https://<yourusername>.github.io/`.

GitHub's official documentation notes that Pages sites can be created directly from a repository and may take several minutes to publish.
